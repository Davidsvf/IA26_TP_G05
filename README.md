## Objetivo

Desenvolver um agente inteligente para um problema de recolha e distribuição de produtos alimentares locais, considerando produtores, clientes, veículos, distâncias, tempos de viagem, capacidades e janelas temporais.

## Estrutura

- `Proj01.ipynb` — notebook principal do projeto;
- `EDA.ipynb` — análise exploratória e validação dos dados;
- `data/tiny/` — ficheiros CSV da instância utilizada;
- `README.md` — informação geral do projeto.
